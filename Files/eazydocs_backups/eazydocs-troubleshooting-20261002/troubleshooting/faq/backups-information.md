During system updates, the Nitrux Update Tool System will automatically create a backup of the root partition for rollbacks. However, the Nitrux Update tool System does not create backups of the home partition. To create backups of the user data in the home partition, use Kup Backup.

### Important Notes

 For a detailed tutorial about using Kup, see [Resources → Tutorials → Backups](https://nxos.org/documentation/resources/tutorials/).
