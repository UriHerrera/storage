Nitrux uses a Linux kernel with patches from CachyOS (by ferreo) to ensure uncompromising responsiveness. Nitrux includes desktop launchers for installing [Steam](https://store.steampowered.com/), [Bottles](https://usebottles.com/download/), and the [Heroic Games Launcher](https://heroicgameslauncher.com/) from the applications menu. Alternatively, users can install [Lutris](https://lutris.net/) (from Flathub) to run Windows software. Nitrux includes a desktop launcher to install the [itch.io Store](https://itch.io/) application, which downloads and runs the official Linux installer.

### Important Notes

 The respective install scripts will install the applications in the background. Installation time will vary depending on the speed of the Internet connection. For a detailed tutorial about setting up a gaming environment, see [Resources → Tutorials → Gaming](https://nxos.org/documentation/resources/tutorials/).
