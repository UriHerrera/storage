---
title: "Support for Other Desktop Environments"
eazydocs_id: 14789
---

By default, Nitrux uses Hyprland, Waybar, and Crystal Dock to put together the desktop. However, users can install alternative desktop environments or window managers using Distrobox or by creating an AppBox.

### Information

 For a detailed tutorial on the process, see [Resources → Tutorials → Desktop](https://nxos.org/documentation/resources/tutorials/).
