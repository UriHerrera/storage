The ISO files labeled `nitrux-contemporary-cachy-nvopen` are specifically for NVIDIA GPUs. These ISO files include the NVIDIA Open Kernel Module, OpenRC services for NVIDIA hardware, NVIDIA device nodes initialization, and Dynamic Power Boost D-Bus services.

### Important Notes

 For detailed information regarding the NVIDIA driver, see [Resources → FAQ → NVIDIA Driver Information](https://nxos.org/documentation/troubleshooting/faq/nvidia-driver-information/).
