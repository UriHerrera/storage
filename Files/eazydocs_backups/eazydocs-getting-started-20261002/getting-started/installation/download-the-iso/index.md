We offer users various ways to obtain the correct ISO file to install the distribution.

- Directly from our website. 
    - <https://nxos.org/get/latest/>
- Mirrors from Sourceforge. 
    - [https://sourceforge.net/projects/nitruxos/files/Release](https://sourceforge.net/projects/nitruxos/files/Release/)
 
 Other third-party alternatives are available. However, these might not be up-to-date: - Torrent file from FOSSTorrents.com. 
    - <https://fosstorrents.com/distributions/nitrux/>
 
### Important Notes

 Download the correct ISO file for the target hardware. HCVL validates the GPU compatibility with the selected ISO flavor; if the validation fails, the system will reboot.
