[GtkHash](https://gtkhash.org/) is a graphical application available from Flathub. After installing the application, select the ISO file. \[divider line\_type="undefined" custom\_height="10"\] ![](https://nxos.org/wp-content/uploads/2021/12/Screenshot_20240601_173231.png) \[divider line\_type="undefined" custom\_height="10"\] After selecting the ISO file, open the preferences and enable SHA512. \[divider line\_type="undefined" custom\_height="10"\] ![](https://nxos.org/wp-content/uploads/2021/12/Screenshot_20240601_173336.png)\[divider line\_type="undefined" custom\_height="10"\] Then, after downloading the SHA512 checksum file, paste the checksum into GtkHash and click the "Calculate" button. The application will indicate whether the checksum matches. \[divider line\_type="undefined" custom\_height="10"\] ![](https://nxos.org/wp-content/uploads/2021/12/Screenshot_20240601_173424.png)\[divider line\_type="undefined" custom\_height="10"\]
