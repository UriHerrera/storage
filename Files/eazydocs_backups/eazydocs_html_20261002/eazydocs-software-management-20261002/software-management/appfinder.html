AppFinder is a software-management GUI for Nitrux. Built with MauiKit, it brings together the supported ways to obtain, build, and manage software while keeping those workflows separate from the immutable base system.

Software Sources

  • Flathub: Browse featured applications, collections, and categories; search for applications; install, launch, update, and remove Flatpaks; and manage optional Flatpak add-ons.
  • NX AppHub: Browse curated AppBox recipes, refresh the local applications repository, activate or remove AppBoxes, launch installed AppBoxes, and restore AppBox backups.
  • Personal Bundle Builder: Create and edit local AppImage bundle projects, configure their package sources, dependencies, integration, launch options, and sandboxing, then save and build the bundles locally.
  • Distrobox: Create and manage development containers using a selected base image, with controls to start, stop, open, clone, repair, and delete containers.

Usage

Launch AppFinder from the application menu or run it from the terminal:


appfinder

Use the navigation sidebar to switch between NX AppHub, Flathub, and Distrobox. AppFinder can refresh Flathub, NX AppHub, and Distrobox data automatically when it starts. This behavior, the initial Flathub view, and sidebar visibility can be changed in Preferences.

NX AppHub

The NX AppHub view has three areas:

  • Explore NX AppHub: Browse and search curated AppBox recipes. Refresh the local applications repository when new recipes are available.
  • Personal Bundle Builder: Build a personal AppImage from a local recipe. A generated project can be edited before saving or building it.
  • Installed AppBoxes: Launch or remove installed AppBoxes and restore an available backup.

AppBox recipes are built through nx-apphub-cli. For details, see the NX AppHub Wiki, the NX AppHub Apps Wiki, and the NX AppHub Daemon Wiki.

Flathub

AppFinder uses Flathub for sandboxed desktop applications. The Flathub view provides featured applications, collections, category browsing, search, and an installed-applications view. Selecting an application opens its details, where available actions include installation, launching, updating, removal, and management of optional add-ons.

AppFinder installs applications for the current user by default. System-wide Flatpaks and their runtimes are shown separately when present.

Personal Bundles

The Personal Bundle Builder creates local AppImage projects from package metadata and a selected distribution source. Projects can define package repositories, optional PPAs, dependencies, desktop integration, executable and library paths, metadata, pre-build commands, and optional Bubblewrap or Firejail sandbox settings.

After a project is saved, use Build Bundle to create the AppImage. Built GUI bundles can be opened from AppFinder, while the output location can be revealed from the bundle actions.

Distrobox

The Distrobox view provides mutable development environments without modifying the Nitrux base system. When creating a container, specify its name and base image, such as ubuntu:24.04. You can optionally mount a host directory as the container home.

  • Rootless containers: Run without root privileges and are the default choice for development environments.
  • Rootful containers: Can be created when real root privileges are required. AppFinder can load and refresh the rootful-container inventory.
  • Container actions: Start, stop, open, clone, repair, and delete containers. All containers can also be stopped or deleted from the action bar.

Warning: Rootful containers can modify host-owned resources. Enable this option only when required.
