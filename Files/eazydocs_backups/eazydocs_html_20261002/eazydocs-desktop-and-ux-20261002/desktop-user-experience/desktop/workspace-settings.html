Workspace Settings is a centralized settings manager for Nitrux. Built with MauiKit, it provides configuration pages for desktop, applications, hardware, connectivity, security, and login behavior.

General

  • About → View operating system, session, software, graphics, hardware, memory, and storage information.
  • System → Configure the timezone, locale, date, time, hostname, and user accounts.
  • Accessibility → Configure single-click activation, terminal scrollbar placement, and night light behavior.

Appearance

  • Background → Select wallpapers and configure Hyprpaper wallpaper and runtime options.
  • Theme → Configure MauiKit, Hyprland window appearance, KDE and desktop integration, fonts, GTK themes, icons, cursors, and sound preferences.

Desktop

  • Status Bar → Configure Valenz bar placement, Control Center actions, media controls, weather, screenshots, and screen recording.
  • On-Screen Display → Configure NudgeOSD icon style, dimensions, position, visibility, animation timing, and adjustment controls.
  • Dock → Configure Marina icon size, spacing, screen placement, manual sizing, fullscreen behavior, auto-hide, and launcher shortcuts.
  • Window Compositor → Configure Hyprland layout, gaps, window opacity, blur, animations, and window or layer rules.

Applications

  • MIME Defaults → Manage the applications used to open MIME types and links.
  • Default Applications → Configure the default commands used by the Hyprland desktop, such as the terminal, file manager, web browser, and application launcher.

Connectivity

  • Network → Manage wired and wireless connections, IPv4 and IPv6 settings, DNS servers, DNS encryption, and OpenVPN imports.
  • Bluetooth → Enable Bluetooth, discover devices, manage paired devices, and control trusted connections.

Hardware and Sound

  • Audio → Manage PipeWire playback devices, recording devices, volumes, and application audio streams.
  • Performance → Configure NX Power Daemon thresholds and graphics mode settings.
  • Input Devices → Configure keyboard layouts, pointer behavior, touchpad scrolling, gestures, device-specific settings, and Hyprland keybinds.
  • Battery → View battery charge, estimated time remaining, charge history, health, voltage, technology, and charge cycles.
  • Displays → View display arrangements and configure display management, scaling, resolution, refresh rate, and monitor positions.

Security and Login

  • Greeter → Configure QMLGreet wallpaper, clock formats, visual effects, user presentation, avatars, default Wayland session, and system indicators.
  • Lock Screen → Configure Desklock wallpaper, date and time formats, blur, overlays, avatars, resource monitors, battery and media indicators, cursor visibility, and idle timeouts.
  • Logout Menu → Configure the logout menu icon style, avatar, overlay opacity, system uptime, and action timeout.
  • Autostart → Add, edit, or remove commands that run as user services when the desktop session starts.
  • Environment Variables → Add or remove environment variables exported to applications in the Hyprland session.
  • Flatpak Permissions → Manage network, audio, device, display, filesystem, and environment permissions for installed Flatpak applications.

Important Notes

Workspace Settings applies changes to the configuration files used by the corresponding desktop components. Some system-level changes, such as modifying the hostname, timezone, locale, date, time, or user accounts, may require authentication.
