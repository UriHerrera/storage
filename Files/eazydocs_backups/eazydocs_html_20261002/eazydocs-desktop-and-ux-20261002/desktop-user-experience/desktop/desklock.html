Nitrux ships with Desklock as the session locker, using direct Linux PAM authentication, plus CPU, memory, and network monitors. Desklock also supports native MPRIS discovery, metadata, album art, and playback controls over the session D-Bus, plus configurable fade-in/fade-out durations and clock formats.

Appearance

  • Wallpaper → /usr/share/wallpapers/Blossom/contents/images/4096x2304.png
  • Overlay → Enabled, 76% opacity.
  • Clock → 24-hour time and full date.

Configuration

Desklock stores its user configuration in: ~/.config/desklock/desklock.conf

Information
