Vicinae is a keyboard-driven command launcher for Linux, inspired by Raycast. It puts common actions within keyboard reach: launching apps, switching windows, managing clipboard history, searching for files, and more.

Usage

  • Application launcher → Super + R
  • Clipboard → Super + Shift + V

Vicinae Defaults

  • Theme → Catppuccin Mocha.
  • Font → Switzer.
  • Font Size →

10.

  • Icon Theme → Lüv.
  • Window Opacity → 0.9.

Configuration

  • ~/.config/vicinae/settings.json → Vicinae settings
