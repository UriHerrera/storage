MauiKit is a modular UI framework for building convergent applications.

What is MauiKit?

MauiKit is a set of templated controls and tools based on Qt Quick Controls

  1. It provides ready-to-use components that follow the Maui Human Interface Guidelines, enabling rapid application development that works seamlessly across desktop and mobile form factors.
  • Platform-specialized → Components focus on Linux.
  • Convergent → Single codebase for desktop and mobile
  • LGPL 3 licensed → Free to use, copy, merge, publish, and distribute

Why MauiKit?

MauiKit allows developers to build polished, consistent applications using Qt, QML, and C++ with minimal boilerplate. The framework provides UI components designed for both touch and pointer input, blurring the line between desktop and mobile experiences.

Information

Nitrux uses a custom fork of MauiKit tailored specifically for Linux and the hardware requirements of our distribution. This fork does not target other platforms.
