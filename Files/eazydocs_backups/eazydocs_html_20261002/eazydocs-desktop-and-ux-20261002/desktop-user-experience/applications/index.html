Nitrux ships with a curated set of GUI applications for daily use.

MauiKit Apps

Built with MauiKit, Nitrux's convergent UI framework:

  • Index → File manager.
  • Nota → Text editor.
  • Station → Terminal emulator.
  • Pix → Image gallery.
  • VVave → Music player.
  • Shelf → PDF viewer.
  • Fiery → Web browser.
  • Cinderward → Firewall GUI.
  • Wirecloak → WireGuard VPN client.
  • Buho → Note-taking utility.
  • AppFinder → Software manager.
  • Workspace Settings → Primary control center.

Additional Software

  • NVIDIA X Server Settings → NVIDIA hardware management utility.
  • KDE Partition Manager → KDE partition management utility.

Specialized Software

  • VxM → A hypervisor orchestration utility for Nitrux.

Information

Nitrux includes ready-to-use installers accessible from the applications launcher for the following software, which we don't install by default:

  • Steam → Valve's game and software distribution platform.
  • LibreOffice → FOSS office productivity suite
  • Heroic Games Launcher → FOSS launcher for Epic, GOG, and Amazon Prime games.
  • Bottles → Run Windows software.
  • itch.io → Software distribution platform for indie games.

VxM is a command-line program and is only available in the terminal. For more information, see the VxM wiki.
