Installing Nitrux alongside other Linux distributions follows the same process described above.

  1. Disable Secure Boot using your device's firmware.
  2. After disabling Secure Boot, do either of the following:
  3. Boot the Nitrux ISO, launch the installer, select "Install alongside," and click on an existing partition with sufficient space. Adjust the slider to allocate space for Nitrux.
